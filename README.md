# Traveling Broke and Ugly

Personal travel blog at https://travelingbrokeandugly.org, using [Jekyll](https://jekyllrb.com/) and the MIT-licensed [Long Haul](https://github.com/brianmaierjr/long-haul) theme by Brian Maier Jr.

## Local preview

Install Ruby and Bundler, then run `bundle install` and `bundle exec jekyll serve`.

The site's configuration is in `_config.yml`; new blog posts belong in `_posts/` as dated Markdown files. Preserve `CNAME` for the custom domain.

To publish, configure GitHub Pages to deploy from branch `main` at `/(root)`.
